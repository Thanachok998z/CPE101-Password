# CPE101-Password

Password Game in C (Win32 GUI), with password rules, save/resume, and timer.

## Build on Windows

Install MinGW GCC and run uild_windows.bat.

## Files

- main.c: game source code
- uild_windows.bat: build and run script
- README_TH.txt and README_SAVE.txt: usage notes

Saved gameplay data and compiled binaries are intentionally ignored.
