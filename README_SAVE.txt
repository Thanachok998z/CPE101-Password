Password Game C v6 - Save & Timer

Build: double-click build_windows.bat (MinGW GCC needed).

Each 11-digit student ID gets a separate file in data/save_<ID>.bin.
Game saves when password changes, every 10 seconds, when switching students, when winning, or when closing.
Sign in with the SAME student ID to resume the password, unlocked rules, final confirmation stage and accumulated play time.
Time counts only while the app is running and the game is not won, not while closed.
SAVE GAME button forces an immediate save. SWITCH STUDENT preserves old progress.
Previous v5 versions had no progress saves and cannot be restored retroactively.
Note: local save stores game password in readable/recoverable binary; do not use a real account password.
